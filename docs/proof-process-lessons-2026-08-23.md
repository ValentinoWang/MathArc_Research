# Proof-process lessons absorbed into MathArc Research v0.1

Status date: 2026-08-23

The Frankl q=6 closure changed the engineering contract in six concrete ways.

1. **Compressed search needs an uncompressed audit.** A maximum-cost representative is useful for discovery, but the release gate now requires either a proved compression map or an exhaustive audit of every underlying type. The q=6 run therefore checked all `244,068` trace-type multisets after the compressed pass.
2. **Exceptional cases become regression objects.** The final eight q=6 exception classes remain named, counted, and replayed instead of disappearing inside an aggregate estimate.
3. **Cold replay is a release artifact.** Byte-identical independent process replays and their SHA-256 digests are part of the evidence package.
4. **Scope closure stays binary.** The frozen q=6 special case can be `1/1` while the full Frankl conjecture remains `0/1 INCONCLUSIVE`.
5. **Generation and acceptance are separate authorities.** Codex workers may propose claims, commands, and file changes; they cannot emit an accepted or verified mathematical state.
6. **Web UX must expose the actual research process.** Public reasoning summaries, command execution, file changes, tool errors, evidence debt, dependency invalidation, and claim boundaries are streamed as first-class events.

These rules are enforced by the Codex output schema, claim DAG, verifier policy, API security boundary, acceptance script, regression tests, and v0.1 release documentation.
