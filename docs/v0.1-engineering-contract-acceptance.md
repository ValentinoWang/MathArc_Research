## 4. Codex acceptance boundary

The official Codex CLI is invoked with JSONL output and a strict final JSON Schema. Its allowed final statuses are:

```text
progress
blocked
falsified
candidate
error
```

It cannot output `VERIFIED` or `ACCEPTED` as a state transition. A Codex turn can generate files and execute commands only within the selected sandbox; it cannot alter MathArc's mathematical release state. Claim promotion still requires accepted evidence whose scope and trust cover the claim and whose dependencies are already verified.

## 5. Proof-process lessons absorbed

### 5.1 Compression requires an uncompressed audit

The Frankl q=6 program first compressed trace-type states by aggregate deficit and cost. A later exhaustive audit of all 244,068 residual trace-type multisets exposed additional exceptional categories. v0.1 therefore records:

> No compressed exhaustive argument may close a root obligation until a second audit checks the compression map or enumerates the uncompressed state space.

### 5.2 Cold replay is a release gate

The q=6 monolithic verifier produced byte-identical accepted JSON on two cold starts. v0.1 treats deterministic replay identity as a release artifact with content hashes, not a narrative assertion.

### 5.3 Special-case and global states stay separate

The q=6 minimum-three-set bridge is internally proof-complete for its frozen contract, while Frankl's full conjecture remains inconclusive. The dashboard and Agent prompt expose both states separately.

### 5.4 Failure information is first-class

False recurrences, hidden assumptions, exceptional trace types and checker disagreement are retained as failures or regression fixtures. A route cannot erase a failed mechanism by changing wording.

### 5.5 Generator and checker independence are visible

The evidence ledger exposes producer identity, trust level, scope, replay command and independence relation. Model agreement is never counted as independent mathematical reconstruction.

### 5.6 Public reasoning summary replaces unverifiable introspection

The Web UI displays objective, premises, action, observation, falsification and decision, together with actual commands and artifacts. It does not present private token-level model reasoning as proof.
