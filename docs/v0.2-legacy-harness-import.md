# Importing legacy proof-research harnesses

MathArc v0.2 treats older harness results as evidence-bearing research history, not as automatically verified v0.2 claims.

## Why the adapter is conservative

A legacy run may report all of the following at once:

- `valid=true` for the harness schema;
- several nodes marked `PROVED_AND_AUDITED`;
- a weighted progress value such as 82%;
- `acceptance_records=0`;
- `full_conjecture_logical_closure=0/1`.

These fields are compatible. They mean that the run can contain exact local theorems while the global conjecture remains open. Schema validity and extensive computation do not create a missing universal bridge.

The importer therefore preserves three different facts separately:

1. what the old run claimed about a node;
2. what audit metadata was present;
3. what v0.2 is permitted to release after replay.

## Policies

### `metadata_only`

This is the default. Imported closed nodes become `SUPPORTED`; none become `VERIFIED`. The source status, statement, scope limit and open obligations remain visible.

### `replay_manifest`

An imported node may become `VERIFIED` only when its acceptance record contains:

- an artifact SHA-256;
- a statement SHA-256;
- a replay command;
- a passing result;
- an independent reconstruction when the policy requires it;
- a valid legacy validation record with no errors.

Even then, a verified local node does not close the theorem while any critical obligation remains open.

## Command

```bash
python scripts/import_legacy_harness.py \
  --progress path/to/progress.json \
  --validation path/to/validation.json \
  --policy metadata_only \
  --output artifacts/imported-run.json
```

To request promotion from a replay manifest:

```bash
python scripts/import_legacy_harness.py \
  --progress path/to/progress.json \
  --validation path/to/validation.json \
  --acceptance-manifest path/to/acceptance.json \
  --policy replay_manifest \
  --output artifacts/imported-run.json
```

## Claim boundary

The adapter does not prove the source theorem. It prevents exact local work, failed routes and open obligations from being lost while refusing to convert research progress into theorem closure without replayable evidence.
