Blocking findings to close

1. Restoring a previously valid state + authentication + literature tuple after
   advancing c1 -> c2 must not make a fresh runner accept c1. The freshness
   commitment must live in the signing-authority boundary, not in another
   attacker-restorable data-path sidecar. Define and test the exact threat
   boundary. Do not claim protection from a same-user compromise that can read
   or mutate the signing authority.
2. A crash after literature persistence but before state/auth persistence, and
   a crash between state and auth replacement, must be recoverable on restart.
   Use a durable transaction/journal or equivalent protocol. Recovery must
   restore or complete one authenticated committed generation and must not
   silently accept a mixed tuple. Cover first-write and later-generation edges.
3. next_cursor and manual_queue must reload current persisted LiteratureBase
   state under the runner lock before authenticating; a long-lived runner must
   not validate a stale in-memory snapshot.
4. EXISTING_OBSERVED must permit the persisted observation ID to differ from
   the input observation ID when logical identity, content digest, artifact,
   and idempotency binding all match. Restart must accept the recorded result.
5. The topic state path must enforce the same non-symlink regular-file and 0600
   policy as the authentication/signing boundary. Avoid lstat/read pathname
   TOCTOU where practical by reading from the verified file descriptor.
6. Source identity must preserve case-sensitive URI path semantics and use an
   unambiguous structured encoding instead of delimiter concatenation. Preserve
   normal URI host/scheme normalization. Add collision tests for path case and
   embedded vertical bars. Update any state schema/recovery contract needed so
   old incompatible state is not silently reinterpreted.

  permission-invalid, symlinked, inconsistent, or unauthenticated.
- Reuse existing atomic-write, canonical JSON, ArtifactStore, and writer-lock
  patterns. Keep the protocol local and bounded; no database or platform rewrite.
- Persisted authority/journal state must be private, deterministic to validate,
  and explicitly versioned. A high-water counter stored beside auth with the

- Artifact created_at remains provenance-only; do not expand scope to that P3.
- Do not edit historical implementation logs to fix whitespace.
- Add direct red/green regression tests for every numbered finding above.
