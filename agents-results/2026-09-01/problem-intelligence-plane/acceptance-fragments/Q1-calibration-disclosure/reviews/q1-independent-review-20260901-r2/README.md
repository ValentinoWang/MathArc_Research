# Q1 Independent Review Campaign (r2)

This campaign supersedes the wrapper-invalidated r1 attempt while retaining
that attempt as audit history. It is frozen against the same Q1 candidate and
requires two zero-write, independent reviews using the host's existing
`run-l3.sh` and `run-l4.sh` wrappers.

The reports are review evidence only. They do not accept Q1, authorize A5, or
authorize public release.
